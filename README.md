# Zaker AI — ذاكر بذكاء

تطبيق Flutter تجريبي احترافي للمذاكرة بالذكاء الاصطناعي.

## التشغيل من GitHub Actions
1. ارفع كل الملفات على GitHub.
2. افتح Actions.
3. شغّل Build Android APK.
4. حمّل Artifact باسم zaker-ai-apk.
5. ثبّت app-release.apk على هاتف أندرويد.

## التعديل
أهم ملف للتعديل:
- lib/main.dart

غيّر النصوص والألوان والأزرار من هذا الملف.
