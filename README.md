# Zaker AI — ذاكر بذكاء

تطبيق Flutter تجريبي بواجهة احترافية لتطبيق مذاكرة بالذكاء الاصطناعي.

## تشغيله من الموبايل فقط

1. ارفع ملفات المشروع على GitHub.
2. افتح تبويب Actions.
3. شغّل Workflow باسم Build Android APK.
4. بعد اكتمال البناء، حمّل ملف zaker-ai-apk من Artifacts.
5. فك الضغط وثبّت app-release.apk على موبايل أندرويد.

## التعديل

أهم ملف للتعديل:
- lib/main.dart

تقدر تغيّر النصوص، الألوان، أسماء الأزرار، والشاشات من هذا الملف.
